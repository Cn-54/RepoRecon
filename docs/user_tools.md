# User Tools

Tools for GitHub user reconnaissance.

## Tools

* [Relationship Grapher](user/relationship_grapher.md)

  * Finds GitHub followers and following
  * Builds relationships between accounts
  * Supports configurable graph depth
  * Supports configurable connections per account
  * Generates an interactive HTML graph

* [Mutual Grapher](user/mutual_grapher.md)

  * Finds mutual GitHub relationships
  * Builds relationships between accounts
  * Supports configurable graph depth
  * Supports configurable mutuals per account
  * Generates an interactive HTML graph
